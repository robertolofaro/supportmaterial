The purpose of this experiment was to see which key elements each model would identify to ensure transparency and auditability of an AI-to-AI language. 

The idea derives from my experience in the 1980s on PROLOG and Decision Support Systems, augmented from the 1990s with cultural and organizational change activities, where often had to define formally sound organizational documents that, at least in the initial release, tried to be narrative but non-ambiguous, e.g. by mapping boundaries and overlaps and identifying the transitions across different internal and external organizational units.

Models involved: Claude, DeepSeek, Gemini, Grok, Kimi, Qwen (the list above shows the models that Claude decided to consult). 

The prompt was given to the six online AIs, no modification was done to the Markdown of the answers< Claude, elected to use a mixed DOCX and Markdown answer: ChatGPT was not accessible.

ChatGPT did not allow access at the time of the experiment.

The differences in BNF definitions are a mirror of each model logic

Experiment carried out on 2026-02-23@09:00 CET, answers reported “as is” (except for changes documented in the first page of the Acrobat document).

The next step would be having AIs by consensus developing a language set and updated by AIs, but
audited by humans with the collaboration of other Ais, due to the volume and frequency of information
transacted that would make mere human supervision not feasible.

This repository will be updated (along with this README.md) whenever new material will be released.

The first step, before further developing a first vocabulary and set of documentation pages, has been to produce a fictional standard and associated test suite for exchanging messages (for now using natural language, eventually replaced with elements from the vocabulary), and associated BNF.

The initial "consolidator" was Claude, in the Acrobat version that you can see here, while then the first draft fake-standard producer based upon a document including all the material from the other models (including Claude) was ChatGPT, and the test suite and initial version was developed and tested with DeepSeek.

The document, developed along with different AIs, along with a full test suite to exchange and validate messages and implementation, has been released on 2026-02-25 as a [Jupyter Notebook on Kaggle](https://www.kaggle.com/code/robertolofaro/standardproposal-updated-20260225)

The test suite will be released here in early March 2026, when a full narrative of the experiment and ongoing next steps will be published.
