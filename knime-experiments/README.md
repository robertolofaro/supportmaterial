This directory contains the Knime sample workflows created to support my publications- each workflow will have the same title of the publication that it supports, with a counter appended to the name in case a publication includes more than one workflow.

Do not expect anything complex as would do for customers or to create tools- also because it is an ongoing learning.

The aim is simply to provide a further tool to replicate charts and analyses, thanks to the intuitive interface of Knime.

Generally, you will need just to replace the input data source(s) with your own (with the same and, if needed, additional data columns) and then "execute" the nodes.

Each workflow uploaded here is CC-BY-SA-4.0 unless otherwise stated, and often there will be a companion Kaggle dataset, to enable more advanced analyses and reuses.

If a Kaggle dataset is available, it will be described within the information associated with the workflow.
