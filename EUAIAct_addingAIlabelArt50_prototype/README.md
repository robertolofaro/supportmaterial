# AI Etiquette beyond the mere formal requirements

* Prototype to test concepts, do not use it for compliance
* Seek formal legal advice before using it for compliance with the EU AI Act
* Software designed by Roberto Lofaro, developed with Kimi and Grok
* CC-BY-SA-4.0 2026-08-09 https://linkedin.com/in/robertolofaro

Formally, the AI EU Act Art. 50 requires to add a label to multimedia and material generated or modified with the use of AI.

Currently the only AI images that created or modified with AI and shared routinely online since last year are about my fictional ["United Hamster Front"](https://www.facebook.com/61580594577830/)

All free material (formally: CC-BY-SA-4.0).

In the future, might add other material to complement both that and [my YouTube channel on change](https://youtube.com/@changerulebook)

Formally, as shown e.g. [in this Q&A tool](https://www.label-or-not.com/) this should be compulsory for professional publishers and users.

Personally, I think that a minimal set of elements (the label plus the machine-readable watermark and metadata posted within the image) should be a matter of shared interest-

Or: anybody who shares online or offline with unknowns something that has been generated by or modified with AI should clearly mark so- also when it is not for professional uses.

The earlier we do, the earlier we will start getting used to it and develop a (n evolving) consensus on "how" to do it, as there are still too many who forward to others material without understanding that it is AI-generated or AI-modified.

Therefore, while I already shared in the past when content that posted was AI-generated or AI-modified, both multimedia and text, I waited a week since 2026-08-02.

I wanted to see how many labels would I see on the platforms where most of the material is frankly AI-generated: Instagram and Linkedin.

Answer: none.

On Facebook, alreaady a while ago images supporting text were generally stating explicitly if had been involving AIs, when it was not immediately visible.

The files in this directory include:
**the software**
* cli.py: the main tool to launch- launch without parameters (e.g. <code>python3 cli.py</code>) and will show the help on how to use it
* config.py: an optional configuration file (you can pass instead parameters from the command line): consider it an example
* eu_ai_act_labeler.py: the main component carrying out all the work
* watermark_check.py: a simple script to show the main information- it is a prototype, can be easily extended, e.g. for c2pa or other information
* c2pa_prevenance.py: for now, just a draft, to add also in the future digital signatures etc
**the examples**
* GeneratedWithZImageTurbo_ai_labeled.sh: a minimal command-line linux script to convert a single image without using the config.py
* GeneratedWithZImageTurbo_ai_labeled.png: the resulting image (the input is not shared, as contained the prompt), containing both label and metadata clearly stating that it has been fully generated with AI
* removepeople_building_ai_labeled.sh: a minimal command-line linux script to convert a single image without using the config.py
* removepeople_building_ai_labeled.png: the resulting image (ditto), containing both lable and metadata clearly stating that it has been modified using AI

It is just a prototype to visually test the concept also for my publications online or sharing with others, but consider it a "concept that actually is usable".
