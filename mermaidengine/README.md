This directory contains examples from a tool that developed to support my publications.

The [tool is available here](https://robertolofaro.com/diagrams_tool.php), and adds the syntax for the following diagram types:
* waterfall
* bubble chart
as currently were not within those supported.

You can read an explanation of the development process on my article released on 2026-03-18 [Organizational Support 16: Walking the talk- adding waterfall and bubble chart Mermaid-style](https://robertolofaro.com/index.php?page=645) 

If the site is unavailable or you prefer to retrieve the article text [it is available here](https://github.com/robertolofaro/supportmaterial/blob/master/kagglemetadata_content/file_645_content.txt)

As I wrote within the article and [on a post on Linkedin](https://www.linkedin.com/posts/robertolofaro_github-robertolofarosupportmaterial-activity-7440112614417801216-EBi1?utm_source=share&utm_medium=member_desktop&rcm=ACoAAAAUT8sBHrqxYdQXQm0hH6hcF5fnJ-Z7AMg), if you look at the source of the webpage of the tool you should be able to see all the JavaScript that defines both the tool and its rendering components.

Hence, as I will be busy for a while on some publications, if you have spare time, you are welcome to copy the source for both and repackage to submit for integration within Mermaid.js

I will add in the future a library of examples derived from my experience, along with other types of diagrams that could be useful to others too for non-IT diagrams.

Stay tuned

PS: it has been developed in collaboration with 6 different AIs, online and offline
